dvq — Data Validator Quick

Check a CSV for the data problems that break pipelines silently

git clone https://github.com/contentforge-press/dvq

What it catches

  • 2026-02-30 in a date column — parses fine, does not exist
  • "$1,250.00" in a number column — becomes NaN, written as null
  • The same key twice (A-001 and A-1) — joins duplicate every row
  • N/A where you expected empty — passes a null check, poisons the join
  • "A-1001 " trailing space — Merge returns zero rows, no error
